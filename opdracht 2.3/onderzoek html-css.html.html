Onderzoek HTML & CSS

Waarom noem je de eerste HTML-pagina meestal index.html?

De eerste pagina van een website wordt meestal index.html genoemd, omdat dit de naam is die webservers gebruiken om de startpagina van een website te vinden.

Welke HTML-standaard gebruiken webontwikkelaars tegenwoordig en waarom wordt deze een "living standard"genoemd?

De HTML-standaard die wordt gebruikt is HTML5. Het wordt een living standard genoemd omdat het continu wordt bijgewerkt en verbeterd.

Waarom spreken webontwikkelaars tegenwoordig meestal niet meer over één specifieke CSS-versie?

Webontwikkelaars spreken tegenwoordig meestal niet meer over 1 specifieke CSS-versie, omdat na CSS3 is opgesplitst in verschillende versies die allemaal anders zijn.

Waarom ziet een website er soms net iets anders uit in verschillende browsers, zoals Chrome, Firefox of Safari?

Een website ziet er anders uit in verschillende browsers, omdat ze allemaal een eigen manier van het stylen hebben.
